Getting started

From download to first transfer

1

Download the Windows installer

Use the Download for Windows button and select the recommended installer.

2

Install AeroSync

The installer can create Desktop and Start Menu shortcuts.

3

Launch AeroSync

Open AeroSync from the Desktop, Start Menu or installed application.

4

Allow network access

If Windows Firewall asks for permission, allow AeroSync on trusted Private networks.

5

Connect and transfer

Connect both devices to the same Wi-Fi or hotspot and select the discovered device.

1

Download AeroSync.apk

Download the latest Android APK from the GitHub release.

2

Install the APK

If Android asks for permission, allow your browser or file manager to install the APK.

3

Grant required permissions

Allow the permissions requested by AeroSync for file access and device discovery.

4

Join the same network

Connect the Android device and Windows PC to the same Wi-Fi or hotspot.

5

Select a device and transfer

Once the PC appears, pair the devices and start sending files.
